# مرجع بازیابی آریا

مرجع کاربر: https://share.gemini.google/C0POK4CzkTwh

- `gemini-conversation.txt`: متن کامل قابل مشاهدهٔ مکالمه در زمان بررسی، با حفظ ترتیب و تکرارها؛ شامل درخواست‌ها، دستور زمان‌بندی، بیو، سناریو، فانل دایرکت و متن اسکیل.
- `gemini-studio-dom.html`: DOM کامل پیش‌نمایش استودیو با کد خود برنامه و CSS تولیدشده. تصاویر inline بدون تغییر بایت در فایل‌های محلی قرار گرفته‌اند و مسیرشان جایگزین شده است. اسکریپت‌های تزریقی احراز هویت، دسترسی میکروفون و ارتباط با میزبان Gemini حذف شده‌اند. این فایل بایگانی مرجع است؛ داشبورد عملیاتی در `web/` است.
- `gemini-tabs.txt`: مشاهدهٔ تب‌های کلیدها، استودیو و زمان‌بندی.
- `persian-rtl-vazirmatn-original.txt`: متن اصلی اسکیل، بدون خلاصه‌سازی؛ نسخهٔ قابل استفاده در `.agents/skills/persian-rtl-vazirmatn/SKILL.md` قرار دارد.
- `assets.json`: منشأ و SHA-256 تصاویر. سه JPEG دقیقاً از src تصاویر استودیو استخراج شده‌اند. چهار PNG جداگانه همان خروجی‌های نشانی‌های عمومی تصاویر و فریم اصلاح‌شده هستند. هیچ‌کدام بازطراحی یا دوباره فشرده نشده‌اند.

## محدودیت بازیابی

ضمیمهٔ `aria_motion_story_day1.mp4` در Gemini نمایش داده شد ولی دانلود آن انجام نشد. فایل اصلی هنوز بازیابی نشده است. موتور رندر اصلی پروژه حفظ شده و رندر MP4 جدید از داشبورد ممکن است؛ فایل جدید به عنوان همان فایل اصلی معرفی نمی‌شود.

دو تصویر نخست مکالمه فقط با نشانه‌های `[watermarked_img_963916553365733623.jpg]` و `[watermarked_img_8679432692556047320.jpg]` دیده می‌شوند؛ فایل باینری آن دو نسخهٔ اولیه در لینک عمومی در دسترس نبود. سه تصویر نهایی و نسخه‌های جاسازی‌شده در استودیو بازیابی شدند.

Source view و فایل‌های ضمیمهٔ خصوصی Gemini بدون ورود کامل قابل دریافت نبودند؛ DOM اجرایی استودیو بازیابی شد. تاریخچهٔ Git فایل‌های قبلی پروژه و داشبورد قدیمی را حفظ می‌کند. این بایگانی ادعای دریافت داده‌های پنهان یا فایل‌های غیرقابل دسترس را ندارد.
